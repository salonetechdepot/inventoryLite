# StockEasy — Standard Operating Procedures (SOP v1)

**Who uses this:** Shop owner, cashier, stock keeper  
**When:** Every working day  
**App navigation:** Home · Products · Sell · History · Returns · Account

---

## 1. Roles

| Role | Can do |
|------|--------|
| **Cashier** | Sell, returns, print receipts, search/scan products |
| **Stock keeper** | Add/edit products, adjust stock, print labels |
| **Owner / manager** | All above + day close, credit book, analytics, account settings |

---

## 2. Daily opening

1. Open StockEasy (home screen app if installed).
2. Confirm you are **signed in** (sign in online at least once per day if session expired).
3. Check **internet** if you need Account, day close, or first-time product load.
4. Quick check **Products** — fast-moving items show correct stock.
5. Confirm **printer** is on and has 58mm paper.

---

## 3. Making a sale (standard)

1. Tap **Sell**.
2. Add items by:
   - **Tapping** product card, or
   - **Searching** by name, or
   - **Scanning** barcode (must match product scan code exactly).
3. Tap **Checkout**.
4. Enter payment:
   - **Full payment** — customer pays total.
   - **Part payment** — record amount received; balance goes to credit book.
5. Complete sale → **receipt** appears.
6. Tap **Print** and give receipt to customer.
7. Tap **Done** to close receipt.

**Rules:**

- Always print or show receipt for paid sales.
- Do not sell without recording in StockEasy.
- If scanner fails, use **search by name**.

---

## 4. Credit sales (customer owes balance)

1. At checkout, enter **amount received** less than total.
2. Add **customer name/phone** if prompted.
3. Complete sale — receipt shows **Balance due**.
4. Owner tracks balances under **Account → Credit book**.
5. When customer pays later: Credit book → select customer → **Add payment**.

---

## 5. Returns

1. Find original sale in **History**.
2. Open receipt → start **Return** (or use Returns → Record a return).
3. Select items and quantities to return.
4. Set **condition** and **disposition** (restock vs write-off).
5. Complete return → print return receipt if needed.

**Rules:**

- Always link return to **original sale** when possible.
- Do not restock damaged goods unless manager approves.

---

## 6. Products & stock

### Add new product

1. **Products → Add product**.
2. Enter name, price, category, opening stock.
3. Optional: **Generate** or **Scan** a scan code.
4. **Print label** and stick on shelf/product.
5. Save product.

### Adjust stock

- Small changes: **Products** → **+ / −** on product card.
- Large corrections: edit product or manager review.

**Rules:**

- Every product sold in the shop should exist in StockEasy.
- One scan code per product — no duplicates.

---

## 7. Barcode labels

1. Product must have a **scan code**.
2. Open product (edit) or **Products → tag icon**.
3. Wait for **barcode/QR preview** to load.
4. **Print label** — use 58mm settings (see validation checklist).
5. Affix label where scanner can read it.

---

## 8. Offline rules

When **no internet**:

| Allowed | Not allowed / limited |
|---------|------------------------|
| Make sales | Save day close |
| Returns (if cached data exists) | Account settings |
| Stock adjust (queued) | First login / OTP |
| View History (cached) | |

When internet returns:

- Wait for sync (no action needed usually).
- If **Sync conflicts** appears on Account → resolve with manager.

---

## 9. End of day close (owner/manager)

**Must be online.**

1. **Account → End-of-day close**.
2. Count **physical cash** in drawer.
3. Enter counted amounts.
4. Review **variance** (short/over).
5. Add notes if variance exists.
6. **Save** day close.
7. Investigate large variances before next day opens.

---

## 10. Receipt printing

- Use in-app **Print** button only.
- Paper: **58mm**, margins **none**, headers **off**, scale **100%**.
- If print is blank: wait for barcode/receipt to load → try again.
- If still failing: use **Save image** (labels) or reprint from **History**.

---

## 11. Escalation

| Problem | Action |
|---------|--------|
| App won't sign in | Check internet; retry OTP |
| Sale stuck offline | Complete sale; sync when online |
| Sync conflict | Account → Sync conflicts → manager resolves |
| Wrong price sold | Manager edit product; note in day close notes |
| Printer not working | Check paper/power; use PDF test; contact support |
